# Assets

These images are the Truckee Roundhouse's own artwork, copied from truckeeroundhouse.org
(`/makerspace` for the shop icons; the favicon for the generic bulb; the site header for the
logo). They are embedded in the generated page. Check with the Roundhouse before sharing the
page beyond personal use.

- `icons/wood.png`, `metal.png`, `textiles.png`, `ceramics.png`, `tech.png`: the shop icons.
- `icons/generic.png`: the lightbulb with a wrench, used for anything outside those five shops.
- `logo.png`: the Truckee Roundhouse logo, transparent background.

The six icons were resized to 128 px and normalised so they match: one circle fill colour
(#e6f1ee), one bulb brown (#ad6036), and the same outline weight. The originals came in three
different fills, the textiles outline was heavier, and the generic bulb had no outline. The bulb
artwork itself is unchanged. This was a one-time image edit; there is no code that regenerates
these files.
